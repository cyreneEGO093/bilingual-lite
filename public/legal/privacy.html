双语轻译隐私说明

更新日期：2026-10-04。适用版本：0.5.0。

谁接收数据

本扩展不运营翻译服务器，不向扩展作者发送遥测、广告数据、使用统计或错误日志。翻译使用您配置的 API Endpoint（默认 OpenRouter），以及该服务为您选择的模型提供方。服务方可能记录、保存或处理请求，适用其各自条款和隐私政策。扩展不能代为删除这些服务端记录。

何时发送什么

只有您开启网页翻译、点击图片翻译／框选翻译，或手动重试时，才发送相应内容。滚动模式在开启后持续处理可见段落；整页模式分批处理当前及之后加载的合格段落。关闭翻译停止后续排队，已发出的请求可能继续完成并产生费用。

点击“翻译整页图片”会逐张发送当前页面已经加载、符合尺寸的图片，包括屏幕外的图片；不会自动翻页或滚动加载。可点击停止后续图片队列，已发出的请求仍可能完成并计费。右键图片翻译仅处理选中的图片。

文本请求包含待译段落、目标语言、模型名称、您填写的作品背景和本批匹配的术语；图片请求包含压缩后的整图或所选区域及背景、术语。网页文字和图像可能包含个人信息，请仅翻译您愿意提供给该服务的内容。不会另外发送网页标题、整页 URL、浏览历史或网站 Cookie 作为翻译元数据。

API Key 保存在本机，发送请求时作为 Authorization 认证头交给您配置的 API 服务。“连接并查询模型”会保存配置并向该地址查询模型列表；有 Key 时也会发送认证头，查询不包含页面内容。云端 API 地址必须为 HTTPS，本机回环地址可使用 HTTP。

当无法直接读取图片时，扩展会从原图片服务器下载图片。图片服务器会看到请求的图片 URL、网络连接信息以及浏览器产生的必要请求信息；不携带网站 Cookie 或 API Key。Pixiv CDN 下载使用固定来源 https://www.pixiv.net/，不发送具体作品页 URL。远程下载仅使用 HTTPS，不跟随重定向；本机测试地址除外。

本机保存与清除

Key、API 地址、模型、语言、翻译范围、外观和自定义术语仅保存在 storage.local，不通过扩展同步到其他设备。Key 不是由本扩展额外加密的密码库，本机账户或浏览器配置被访问时可能被读取。

网页原文与译文可能保存在后台内存缓存（最多 500 段），不写入持久化存储。图片译文、手动框位和用于重复图片复用的共享结果（最多 50 项）只保存在当前页面内存，刷新后清除；后台重启清理文本缓存。扩展不在隐私浏览窗口运行，避免跨普通与隐私窗口共享翻译缓存。

您可在设置中修改或清空 Key、背景和术语；停止翻译可停止后续页面请求；卸载扩展会移除其浏览器存储。上述操作不会撤销已发出的请求或删除第三方 API 服务的记录。

权限与用户控制

Firefox 安装时使用内置数据传输同意机制，声明网站内容和认证信息。网页和图片翻译在每个页面默认关闭；悬停按钮本身不会发送图片。

全站访问用于在您访问的网页显示翻译界面、访问自定义 API 和按需下载跨域图片；storage 保存配置，activeTab 与 contextMenus 提供页面／右键操作，declarativeNetRequestWithHostAccess 仅为扩展自身的 Pixiv CDN 下载补上固定来源。扩展不载入远程可执行代码，模型输出仅作为文本和受校验的坐标渲染。
