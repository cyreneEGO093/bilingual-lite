# 双语轻译 · Bilingual Lite v0.5.0

增加桌面整页图片翻译，改进右键图片翻译、移动端浮动入口和小气泡调整工具。

- 桌面点击“翻译整页图片”，依次处理当前页面已经加载的合适图片，包括屏幕外图片；显示进度，再次点击可停止后续任务。不会自动滚动、翻页或打开图库。
- 图片右键菜单“双语轻译：翻译此图片”直接翻译对应图片，避免误用上一次右键的目标。
- 手机收起状态的“译”入口不再追随普通卡片、链接移动；保留输入区和固定控件避让。状态提示独立于工具布局，避免提示消失时改变工具位置。
- 手机阅读时隐藏气泡内的移动／缩放手柄。点击“校准位置”、选择译文框后，使用框外的“移动／缩放／完成”工具，小气泡不再被内部按钮盖住。

验证：102 项自动测试；桌面 Chrome 153 / Firefox 155 与 Android 14 模拟器 / Firefox 157 的实际扩展交互测试通过。包含 Firefox 原生右键菜单、整页图片、重复图片复用、大幅滚动、小气泡框外工具、软键盘与横屏。尚未在实体手机验收，快速滚动效果仍需结合实际设备观察。全部使用本地模拟 API，付费模型开销为零。Mozilla 检查为 0 errors / 0 warnings / 0 notices。

附加调整：整页图片队列串行执行，认证／余额／限流等错误或连续三次失败会停止后续任务。单张偶发错误不终止整批。当前页面最多复用 50 项图片结果；停止任务不会撤销已经发出的请求。批量翻译可能增加 API 用量，隐私说明已补充相应行为。没有新增权限或依赖。
