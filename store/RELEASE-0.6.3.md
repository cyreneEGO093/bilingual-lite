# 双语轻译 v0.6.3

- 新增“输出 Token 上限”设置，默认 1500，可设为 128–65536 的整数；适用于网页、选中文本、整图和框选。较长文本可先试 4096 或 8192。
- 截断提示显示当前设置的上限，便于调整；旧配置升级保留原有 1500 预算。
- 提高上限可能增加费用与等待时间，仍受模型自身限制。整页仍分批处理，不自动提高预算或重发。保存设置后需重新开启翻译。

验证：128 项自动测试及 Chrome 153 / Firefox 155 回归；Mozilla lint 0 错误、0 警告、0 提示。本次只用本地模拟 API，无付费推理，未重跑 Android。

安装：bilingual-lite-0.6.3-firefox.zip / bilingual-lite-0.6.3-chrome.zip。审核源码：bilingual-lite-0.6.3-source.zip。Firefox ZIP 未签名，需提交现有商店项目更新；GitHub 发布不代表商店同步更新。
